# Atlas Rush — тестовая сборка

Играть: https://023irene.github.io/atlas-rush-playtest/

Здесь лежит только готовая веб-сборка игры для плейтеста с друзьями. Её выкладывает скрипт из закрытого проекта, поэтому руками здесь ничего не правят: следующая публикация всё перезапишет.

- `site/` — сборка; `site/version.txt` — коммит проекта и время сборки.
- `.github/workflows/pages.yml` — выкладывает `site/` на GitHub Pages после каждого пуша.
